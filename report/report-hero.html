Portfolio project · R · REDCap · Quarto

REDCap starter kit. From REDCap project to quality-checked report.

This kit pulls records from REDCap with REDCapR, uses the project's own data dictionary to drive cleaning and labelling, runs six data quality checks, and renders the status report below. It is demonstrated on a fictional pregnancy cohort with synthetic data.

Read the sample report Code on GitHub

Background: one stripe per week of enrolment in the sample study, brighter in busier weeks.
